# Run the r4lineups Shiny app

Launches the bundled Shiny app for interactive use of key r4lineups
functionality (lineup bias, effective size, face similarity, ROC/CAC).

## Usage

``` r
run_r4lineups_app()
```

## Value

None. Launches a Shiny app.

## Examples

``` r
if (FALSE) { # \dontrun{
run_r4lineups_app()
} # }
```
