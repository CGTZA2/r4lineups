# nortje2012

A data file containing lineup data for 3 independent lineups. 133 rows x
3 columns. Each lineup trial consisted of 133 mock witnesses & 8 lineup
members.

- : Target position for lineup 1 is 3

- : Target position for lineup 2 is 6

- : Target position for lineup 3 is 2

## Usage

``` r
data(nortje2012)
```

## Format

An object of class `tbl_df` (inherits from `tbl`, `data.frame`) with 133
rows and 3 columns.
