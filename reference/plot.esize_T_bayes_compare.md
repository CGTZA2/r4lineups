# Plot method for esize_T_bayes_compare objects

Plots the posterior distribution of Delta = E'\_A - E'\_B as a histogram
with density overlay. A vertical line at zero and shaded probability
mass above/below zero are shown.

## Usage

``` r
# S3 method for class 'esize_T_bayes_compare'
plot(x, ...)
```

## Arguments

- x:

  An object of class `"esize_T_bayes_compare"`.

- ...:

  Further arguments (unused).

## Value

A ggplot object.
