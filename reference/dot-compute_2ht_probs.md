# Compute 2-HT Model Predicted Probabilities

Compute 2-HT Model Predicted Probabilities

## Usage

``` r
.compute_2ht_probs(dP, dA, b, g, L)
```

## Arguments

- dP:

  Detection of culprit presence

- dA:

  Detection of culprit absence

- b:

  Biased selection

- g:

  Guessing

- L:

  Lineup size

## Value

List with tp (target-present) and ta (target-absent) probability vectors
